ENGLISH ADVENTURE USA — PLAYABLE PROTOTYPE

1. Double-click english-adventure-usa.html on your Mac to open it in a browser.
2. Choose Academy for sample lessons, World for playable real-life missions, Speak for pronunciation practice, and Profile for local progress.
3. Text-to-speech uses your device's speech synthesis. Microphone speech recognition depends on browser support, microphone permissions and possibly internet access.
4. Progress is saved in the current browser using localStorage. No Firebase or AI API is connected.
5. This is a standalone HTML/CSS/JavaScript proof of concept, not yet the planned React/TypeScript production application.

For a local development server:
python3 -m http.server 8080
Then open http://localhost:8080/english-adventure-usa.html
